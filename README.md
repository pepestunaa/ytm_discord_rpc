setup
- go this [link](https://discord.com/developers/applications)
- create a new application
- copy the client ID
- clone this repository
- open the cloned repository in your favorite code editor
- let mut drpc = DiscordClient::new(change_with_your_client_id);
- cargo run --release
- run the executable
- enjoy

if you want startup
- win+r
- type shell:startup
- press enter
- drag and drop the executable into the startup folder
- enjoy the presence
